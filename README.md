# 2학년 수학 전단원 전자칠판 게임

최근 만든 `3단원 덧셈과 뺄셈` 게임의 화면 흐름을 따라 만든 2학년 수학 전단원용 다인 플레이 게임입니다. 브라우저에서 바로 실행되는 정적 웹앱이며, 전자칠판에서 학생별 문제 풀이와 결과 저장까지 한 번에 진행할 수 있습니다.

## 실행

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 4173
```

- 학생용 게임: `http://localhost:4173/`
- 교사용 기록 화면: `http://localhost:4173/teacher.html`

## 구성

- `index.html`: 학생용 게임 화면
- `styles.css`: 참고 게임과 같은 보조개샘 AI 클래스 스타일 UI
- `question-bank.js`: 2학년 1학기/2학기 수학 단원별 문제 생성기
- `app.js`: 다인 플레이, 타이머, 채점, 성장 연출, 결과 저장 로직
- `teacher.html`, `teacher-dashboard.js`: 저장된 학습 기록 확인 화면
- `analysis.md`: i-Scream 평가자료 분석 요약

## 학습 범위

- 1학기: 세 자리 수, 여러 가지 도형, 덧셈과 뺄셈, 길이 재기, 분류하기, 곱셈
- 2학기: 네 자리 수, 곱셈구구, 길이 재기, 시각과 시간, 표와 그래프, 규칙 찾기

## 참고 자료

i-Scream 2학년 수학 1학기/2학기 단원평가 HWP 264개를 내려받아 단원 구성과 반복 유형을 분석했고, 원문 문항을 그대로 복사하지 않고 같은 성취기준을 연습하는 생성형 문제로 구성했습니다.
